# Java Practice

Hands-on Java programs written while learning Java for backend development. Programs are organised day by day, with one folder (package) per day and one file per program.

## Contents

| Day | Topic | Programs |
|-----|-------|----------|
| 01 | Variables and data types | Primitives, type casting, data type sizes, swapping without a third variable, boolean flip |
| 02 | Operators | Arithmetic, assignment, increment/decrement, logical, relational |
| 03 | Control statements | Even/odd, largest of two and three, leap year, grades, voting eligibility, season switch, vowel/consonant |
| 04 | Loops | Palindrome, prime numbers, reverse a number, patterns, divisibility check, simple menu |
| 05 | Arrays | Array programs |

## How to Run

1. Clone the repository: `git clone https://github.com/karupothulamalliswari3112/Java-Practice.git`
2. Open it in Eclipse, VS Code or any Java IDE (Java 21 was used).
3. Open a program from any day folder and run its `main` method.
